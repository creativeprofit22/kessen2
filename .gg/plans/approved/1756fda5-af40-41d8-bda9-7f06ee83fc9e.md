## Design

### Pipeline (one command: `sh analysis/run-analysis.sh`)

1. **SDK scan** — run `ps2_analyzer <elf> analysis/out/ps2_analyzer.toml`, then extract every `name@0xADDR` selector from `stubs`/`untracked_stubs` into `analysis/out/sdk-names.csv` (`name,address`) with `awk`.
2. **Ghidra headless** — one `analyzeHeadless` call:
   ```
   analyzeHeadless analysis/out/ghidra kessen2 \
     -import <elf> -overwrite \
     -processor r5900:LE:32:default -cspec default \
     -scriptPath analysis/ghidra;external/PS2Recomp/ps2xRecomp/tools/ghidra \
     -preScript  K2SetAnalysisOptions.java analysis/out/reports/analyzer-options.txt \
     -postScript K2ApplySdkNames.java analysis/out/sdk-names.csv analysis/out/reports/sdk-naming.txt \
     -postScript K2Report.java analysis/out/reports \
     -postScript ExportPS2Functions.java analysis/kessen2.toml analysis/out/kessen2_functions.csv \
     -log analysis/out/reports/ghidra.log -scriptlog analysis/out/reports/scripts.log
   ```
3. **Fix-up** — rewrite `output = …` in `analysis/kessen2.toml` to the repo's `generated/` absolute path (single `sed` on that one key). `input` already points at the ELF under `work/`.

Output locations: `analysis/kessen2.toml` (criterion path), everything else under `analysis/out/`. All ignored by git (new `.gitignore` entries) until the derived-data policy is decided.

### Ghidra scripts (Java, `analysis/ghidra/`)

- **`K2SetAnalysisOptions.java`** (preScript): sets a small, explicit option set and dumps *all* effective analyzer options (name = value, sorted) to the report file so the run is reproducible and documented:
  - `STABS` = on (no-op if there is no `.mdebug`), `MIPS-R5900 Constant Reference Analyzer` = on, `Decompiler Parameter ID` = off (EE README guidance), everything else Ghidra default.
- **`K2ApplySdkNames.java`**: reads `sdk-names.csv`; for each address, creates the function if missing and renames it only if the current name is a default (`FUN_*`) or it has no function — never overwrite an ELF-symtab/STABS name; logs conflicts (different existing name) instead. Uses `SourceType.IMPORTED`. Writes applied/skipped/conflict counts.
- **`K2Report.java`** writes:
  - `summary.txt`: ELF memory blocks; whether a `.mdebug` block exists (→ STABS yes/no, and if yes the count of functions whose names came from STABS); `.symtab` symbol count; total functions; named vs unnamed (`SourceType.DEFAULT` = unnamed) with a per-`SourceType` breakdown; count of SDK-named functions by prefix (`sce*`, `Sif*`, kernel syscalls, libc).
  - `sdk-functions.csv`: `address,name,source` for SDK-named functions (the checklist for the criterion's examples `sceCdRead`, `SifLoadModule`/`sceSifLoadModule`, `sceGs*`, `sceDma*`).
  - `vu0-sites.csv`: every COP2 instruction — `address,function,mnemonic` — matched by mnemonic: `qmfc2`, `qmtc2`, `lqc2`, `sqc2`, `cfc2`, `ctc2`, `vcallms`, `vcallmsr`, and macro-mode `v*` ops (the EE sleigh's VU0 macro mnemonics). Plus `vu0-functions.csv`: per-function counts, sorted descending.
  All output sorted by address for deterministic diffs.

### Driver (`analysis/run-analysis.sh`, POSIX sh like `tools/guard`)

- Inputs via env with defaults: `GHIDRA_INSTALL_DIR`, `K2_JAVA_HOME`, `K2_ELF` (default `work/disc/SLUS-20275/iso/SLUS_202.75`).
- Fails closed with a clear message if Ghidra/JDK/ELF/EE extension is missing; picks `analyzeHeadless.bat` on Windows (`uname` MINGW/MSYS) else `analyzeHeadless`; quotes all paths (the user profile path has a space).
- Logs each stage with elapsed seconds; exits non-zero if any stage fails or an expected output is missing.
